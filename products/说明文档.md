# products/ 说明文档

## 一、内容与作用

本文件夹只存放一个冻结成品：

| 文件 | 大小 | 说明 |
|---|---|---|
| `noise_trends_f8-20Hz_p5.h5` | 约 948 KB（967448 字节） | DAS 噪声振幅时间序列成品，由 `noise_psd/4_analyse_noise_trends.py` 产出 |

它是本包 `noise_psd/` 噪声主线的最终数值产物：在 8–20 Hz 频带内，对每个时间步、每个通道取 PSD 的 5 分位（P5）再开方，得到一条"噪声振幅"代理量。它也是【与 MF 发布版冻结的接口契约成品】——MF 用它把检测能力（最小可检测震级 Mc）和实际噪声水平挂钩。

## 二、逐项说明（字段/数据流）

### 数据流（如何产生）

```
noise_psd/1_calculate_psd_h5.py  →  按天 PSD daily h5 (chunk40min / nperseg200s, 55 通道)
   │  noise_psd/4_analyse_noise_trends.py
   │    · 频带 8–20 Hz 内取 PSD 的第 5 百分位 (P5)
   │    · 开方得到振幅代理:  sqrt(P5 of PSD)
   ▼
products/noise_trends_f8-20Hz_p5.h5   ← 本成品 (冻结)
```

文件名约定：`f8-20Hz` = 频带 8–20 Hz，`p5` = 第 5 百分位（由生成脚本 Config 的 `frequency_band=(8,20)`、`percentile_to_calculate=5` 决定）。

### h5 内容（逐字段，已实测）

**数据集（datasets）**

| 名称 | 形状 | dtype | 含义 |
|---|---|---|---|
| `noise_amplitude` | `(2135, 55)` | `float64` | `[时间步, 通道]`，每格 = 该时间步该通道在 8–20Hz 的 `sqrt(P5 of PSD)` |
| `timestamps_utc_str` | `(2135,)` | `|S19` | 每个时间步的起始 UTC 时间字符串，格式 `%Y-%m-%dT%H:%M:%S`（如 `2024-04-24T10:20:00` … `2024-06-22T17:00:00`） |
| `channels_km` | `(55,)` | `float64` | 通道沿光纤距离（km），0.5 … 15.2 km |

**属性（attributes）**

| 名称 | 值 |
|---|---|
| `amplitude_unit` | `(strain/s)/sqrt(Hz)` |
| `amplitude_description` | `sqrt(P5 of PSD)` |
| `frequency_band_hz` | `(8, 20)` |
| `time_step_duration` | `0:40:00`（每个时间步 40 分钟，与 PSD 计算的 chunk 一致） |
| `description` | `Noise amplitude trend analysis results.` |
| `creation_date_utc` | 生成时刻（如 `2025-07-06T19:37:52...`） |

读取约定：`timestamps_utc_str` 为字节串，使用时需 `decode('utf-8')` 后按 `%Y-%m-%dT%H:%M:%S` 解析；`noise_amplitude` 的两维分别对应 `timestamps_utc_str`（行/时间步）与 `channels_km`（列/通道）。

## 三、与本包其它部分及 MF 的衔接

- 在本包内部：本成品由 `noise_psd/4_analyse_noise_trends.py` 的 `save_results_to_h5()` 写出（同脚本还据它出热力图与逐通道子图）。若需重算，先跑 `noise_psd/1_` 生成按天 PSD，再跑 `noise_psd/4_`。
- **与 MF 发布版（`WANGYuhan2002/yuhan-mfdas`，Zenodo `matched_filter_release.zip` 中为 `yuhan_dasmf_v1.0/`）的冻结接口契约**：`WANGYuhan2002/yuhan-mfdas` 中的 `Run_4_assign_overlaps_with_kurtosis/5_Show_withMag_noise_Mc_bvalue_slip_momentum.py` 直接读取本成品的三个数据集（`noise_amplitude`、`channels_km`、`timestamps_utc_str`），并对 **9–14 km 通道**（`channels_to_avg = [9,10,11,12,13,14]`）沿通道维取均值（`noise_matrix[:, indices].mean(axis=1)`），得到一条噪声振幅时序，用于绘制震级–Mc–b 值–滑移–地震矩综合图。
- 在 Zenodo 归档（`matched_filter_release.zip`）中，该成品也复制了一份在
  `yuhan_dasmf_v1.0/IN_noise_meteo/noise_trends_f8-20Hz_p5.h5`；而在 GitHub 版中，配套仓库 `WANGYuhan2002/yuhan-mfdas` 的 `IN_noise_meteo/` 目录只附带 `load_kefa_meteo.py`，数据文件 `noise_trends_f8-20Hz_p5.h5` 与 `kefa_*_data.csv` 保存在本仓库 `WANGYuhan2002/yuhan_das_spectra`（及 Zenodo 归档）中。
- 因此本成品的三个数据集名称、形状语义（`[时间步, 通道]`）、时间字符串格式与 `channels_km` 数值即对 MF 的稳定接口，不应改动；否则 MF 侧的读取与 9–14 km 取均值逻辑会失效。
