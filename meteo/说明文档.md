# meteo/ 说明文档

## 一、内容与作用

本文件夹是 Kefalonia 部署期的**气象/海况数据链**：把 ERA5 再分析数据落成两个 CSV，并提供一个加载模块，按时间窗读出风速、海浪等要素。

> **数据来源与署名：** 两个 CSV 取自 ERA5 再分析资料（Hersbach et al., 2020, https://doi.org/10.1002/qj.3803）的单点抽取；ERA5 由 ECMWF 为哥白尼气候变化服务（Copernicus Climate Change Service, C3S）制作，经 Copernicus Climate Data Store 获取。Contains modified Copernicus Climate Change Service information. Neither the European Commission nor ECMWF is responsible for any use that may be made of the Copernicus information or data it contains. 数据许可：CC BY 4.0（https://creativecommons.org/licenses/by/4.0/）。另见 `../NOTICE`。

它有两个用途：

1. 在本包内部，供 `noise_psd/2_plot_results_with_wind_wave.py` 把噪声谱和风速/海浪叠加出图（解释噪声随海况起伏）；
2. 对外，是配套 MF 发布版（`WANGYuhan2002/yuhan-mfdas`，Zenodo `matched_filter_release.zip` 中为 `yuhan_dasmf_v1.0/`）`IN_noise_meteo/` 里气象部分的来源（GitHub 版 `yuhan-mfdas` 的 `IN_noise_meteo/` 下仅附带 `load_kefa_meteo.py`，数据文件 `noise_trends_f8-20Hz_p5.h5` 与两个 CSV `kefa_*_data.csv` 保存在本仓库 `WANGYuhan2002/yuhan_das_spectra` 及 Zenodo 归档中）。

文件清单：

| 文件 | 说明 |
|---|---|
| `load_kefa_meteo.py` | 加载模块，函数 `load_kefa_meteo_data(t_start, t_end, data_dir=None)` → `(atmos_df, wave_df)` |
| `kefa_atmos_data.csv` | 大气数据，列：`valid_time, sst, msl, wind_speed, wind_direction`（小时分辨率，约 1423 条记录，2024-04-24 ~ 2024-06-22） |
| `kefa_wave_data.csv` | 海浪数据，列：`valid_time, swh, mwp`（同时间范围、同分辨率） |
| `acquire_era5/0_download_from_api.py` | 一次性获取脚本：用 `cdsapi` 从 CDS 下载 ERA5（区域 `area=[38.6,20.4,38.1,21]`） |
| `acquire_era5/3_to_csv.py` | 一次性转换脚本：读 ERA5 NetCDF，抽点（lat≈38.5, lon≈20.5）后生成上述两个 CSV |

## 二、逐项/逐脚本说明（输入输出/数据流）

### 数据流总览

```
ERA5 (CDS, 需账号/~/.cdsapirc)
   │  acquire_era5/0_download_from_api.py  (cdsapi 下载)
   ▼
ERA5 NetCDF/grib (*.nc)
   │  acquire_era5/3_to_csv.py  (xarray 合并/算风速风向 + 抽点 38.5,20.5)
   ▼
kefa_atmos_data.csv  +  kefa_wave_data.csv   ← 平时只用这两个成品
   │  load_kefa_meteo.load_kefa_meteo_data(t_start, t_end)
   ▼
(atmos_df, wave_df)  → noise_psd/2_ 叠加出图 ；也是 MF IN_noise_meteo 的气象来源
```

### `load_kefa_meteo.py`

- 函数签名：`load_kefa_meteo_data(t_start, t_end, data_dir=None)`。
- 输入：`t_start` / `t_end` 为 `datetime`；`data_dir` 可选，指定两个 CSV 所在目录。
- 行为：分别 `read_csv` 两个 CSV（第 0 列 `valid_time` 作为时间索引），再用 `.loc[t_start:t_end]` 按时间窗切片。
- 输出：`(atmos_df, wave_df)` 两个 `DataFrame`，索引为 datetime；`atmos_df` 含 `sst, msl, wind_speed, wind_direction`，`wave_df` 含 `swh, mwp`。文件缺失或出错时返回 `(None, None)`。
- 去硬编码：原脚本把 CSV 目录写死为绝对路径
  `<作者原工程目录>/check_minmag_validity/Run_4_amp_spec/wind_speed/kefa_wind/`；
  现改为 `data_dir=None` 时默认 = 本模块自身目录（`os.path.dirname(__file__)`，即 `meteo/`，两个 CSV 就在此），并新增可选入参 `data_dir=` 供外部覆盖。**函数名与位置参数 `(t_start, t_end)` 保持不变**，以维持 MF 侧 `from load_kefa_meteo import load_kefa_meteo_data` 的调用契约。
- 仅依赖 `os` + `pandas`（不依赖 `xarray`——后者只在 `acquire_era5/` 重算 CSV 时才需要）。

### `acquire_era5/0_download_from_api.py`

- 作用：用 `cdsapi.Client()` 从 CDS（Climate Data Store）下载 ERA5 数据，分两次请求：
  - 任务 1（大气）：`reanalysis-era5-single-levels-monthly-means`，变量含 `10m_u/v_component_of_wind`、`2m_temperature`、`mean_sea_level_pressure`、`surface_pressure` 等；
  - 任务 2（海浪）：`reanalysis-era5-wave-monthly-means`，变量含 `mean_wave_direction`、`mean_wave_period`、`significant_height_of_combined_wind_waves_and_swell`、`sea_surface_temperature`。
  - 共用参数：`year=2024`、`month=["04","05","06"]`、`area=[38.6,20.4,38.1,21]`、`format=netcdf`。
- 输入：CDS 账号（`~/.cdsapirc`）。输出：`*.nc`（NetCDF）文件。
- 注：需要 `cdsapi` / `xarray` 等额外依赖；属一次性获取步骤，平时不跑。
- 注（GitHub 版补充，代码未改）：这里请求的是**月平均**产品，输出文件名是 `kefalonia_atmospheric_data.nc` / `kefalonia_wave_data.nc`；而 `3_to_csv.py` 读的是 `kefa_wind/data_stream-*.nc` 逐小时文件，随包的 CSV 也是逐小时的。两个脚本按现状接不上，重新下载前请先核对请求。

### `acquire_era5/3_to_csv.py`

- 作用：读上一步的 ERA5 NetCDF，合并大气数据集并由 `u10/v10` 计算 `wind_speed`、`wind_direction`，对目标点（`lat=38.5, lon=20.5`，最近格点）抽取时间序列，时间坐标用 `valid_time`，再导出为 CSV。
- 输出：`kefa_atmos_data.csv`（列 `valid_time, sst, msl, wind_speed, wind_direction`）与 `kefa_wave_data.csv`（列 `valid_time, swh, mwp`）——即本文件夹随包附带的两个成品 CSV。

## 三、与本包其它部分及 MF 的衔接

- 本包内部：`noise_psd/2_plot_results_with_wind_wave.py` 通过 `sys.path` 加入 `meteo/` 后 `from load_kefa_meteo import load_kefa_meteo_data`，调用 `load_kefa_meteo_data(t_start, t_end)` 取 `wave_df['swh']`、`atmos_df['wind_speed']`、`wave_df['mwp']` 叠加在 PSD 谱图旁。
- 对 MF 发布版（配套仓库 `WANGYuhan2002/yuhan-mfdas`，Zenodo `matched_filter_release.zip` 中为 `yuhan_dasmf_v1.0/`）：本文件夹是 MF `IN_noise_meteo/` 中气象部分的来源——在 Zenodo 归档中 `load_kefa_meteo.py`、`kefa_atmos_data.csv`、`kefa_wave_data.csv` 三件均复制进了 `yuhan_dasmf_v1.0/IN_noise_meteo/`；而在 GitHub 版中，`WANGYuhan2002/yuhan-mfdas` 的 `IN_noise_meteo/` 只附带 `load_kefa_meteo.py`，数据文件 `noise_trends_f8-20Hz_p5.h5` 和 `kefa_*_data.csv` 保存在本仓库 `WANGYuhan2002/yuhan_das_spectra`（及 Zenodo 归档）中。MF 侧（`Output_1_SCCs_and_MAD/MAD_arrays/999_plot_MADarr_with_meteo_and_stalta.py`）沿用同一函数签名 `load_kefa_meteo_data(t_start, t_end) → (atmos_df, wave_df)`，使用 `atmos_df['wind_speed']` 与 `wave_df['swh']`。
- 接口契约（冻结）：函数名/位置参数、两个 CSV 的列名（`atmos`: `valid_time,sst,msl,wind_speed,wind_direction`；`wave`: `valid_time,swh,mwp`）即对 MF 的稳定接口，不应改动。
