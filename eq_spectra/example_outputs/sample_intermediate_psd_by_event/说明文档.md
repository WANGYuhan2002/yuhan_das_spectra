# 中间数据范例：单通道逐事件 PSD h5

> **GitHub 版说明：** 这里说的 h5 文件（`psd_data_channel_11.0km.h5`）**不在本仓库里**（它的 HDF5 元数据里有本机路径）；可按下文用 `eq_spectra/1_calculate_psd_by_eq.py` 重算。本包的两个中间产物 h5 样例都不放进 GitHub 版；`noise_psd/` 那个 69.3 MB 的单日 PSD 样例在 Zenodo 存档 [10.5281/zenodo.20715241](https://doi.org/10.5281/zenodo.20715241) 里（`matched_filter_release.zip` → `check_minmag_pkg/noise_psd/example_outputs/sample_intermediate_psd_daily/2024-04-24.h5`）。

`psd_data_channel_11.0km.h5`（~980KB）是 `eq_spectra/1_calculate_psd_by_eq.py` 的**中间产物范例**——某一通道（11.0 km，模板 template_8）上所有地震事件的 PSD。

- **由谁产生**：`1_calculate_psd_by_eq.py`（读 MF 事件目录 `Events_classified_Real_Mag.csv` + 外部 DAS，按事件逐个 Welch PSD）。
- **结构**：每个地震事件一个数据集，数据集 attrs 含该事件 `magnitude` 等；按通道分文件（`psd_data_channel_<km>.h5`）。
- **被谁消费**：`2_plot_psd_by_eq.py`（把按震级分箱的中位地震谱叠在噪声背景上出图）。

> 这里只放**一个通道**作范例参考。全量（各模板 × 各通道，约 1.7GB）不随包附带，可由 `1_calculate_psd_by_eq.py` 在外部 DAS + MF 事件目录上重算。
