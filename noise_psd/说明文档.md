## 一、本文件夹做什么、在包中的位置

`noise_psd/` 是 `check_minmag_pkg` 的**噪声 PSD 主线**（包 README 称「线 A」），即从源工程 `check_minmag_validity/Run_4_amp_spec_final` 抽出、去硬编码后的包内版本。它把 DAS 连续数据转成功率谱密度（PSD），统计其时间-频率-空间分布，并提取一条「噪声振幅随时间变化」的代理曲线，用于解释最小可检测震级 Mc 随海况/风速的变化。

主线数据流一句话：**外部 DAS → 按天 PSD（中间产物）→ noise_trends 噪声振幅 h5（成品）**。

- **本文件夹在包里的位置**：与 `functions/`、`meteo/`、`eq_spectra/`、`products/` 平级（`check_minmag_pkg/noise_psd/`）。脚本顶部统一用
  `_PKG_ROOT = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))`
  推导包根（`1_:32`、`2_:30`、`3_:30`、`4_:30`），再把 `functions/`、`meteo/` 加进 `sys.path`，不写绝对路径、不用环境变量。
- **唯一被下游引用的产物**：`4_analyse_noise_trends.py` 产出的 `noise_trends_f8-20Hz_p5.h5`。它的一份冻结副本已放在包的 `products/`（967 KB，实测存在），被 MF 发布版引用（见第四节）。

## 二、脚本逐个说明

本文件夹只含 4 个根脚本，构成一条「1 产数据 → 2/3/4 各自消费」的流水线。`1_` 必须先跑，`2_/3_/4_` 之间无依赖。

### 2.1 `1_calculate_psd_h5.py` —— PSD 计算与按天存盘（流水线第 1 步，唯一产数据者）

- **作用**：对 DAS 连续数据，逐时间块（chunk）、逐通道用 **Welch 法**算 PSD，按天存 HDF5；带断点续算。
- **输入**：
  - 外部大 DAS（**包内版改为显式顶层变量**）：`DAS_DATA_DIR = os.path.join(_PKG_ROOT, 'IN_DAS_data') + os.sep`（`:38`，GitHub 版默认是包内 `IN_DAS_data/`，可把 80 Hz 归档 `DATA_DEC_80Hz_16m_SORTED/` 放到或软链接到这里；注释「换机改这里」）；Config 里 `self.input_dir = DAS_DATA_DIR`（`:54`）。此目录数十 GB，**不随包带**，PSD 重算才需挂载。
  - 时间窗：当前激活全期 `2024-04-24 10:20 → 2024-06-22 17:10`（`:60-61`，注释里另存 5/2–5/5 测试窗 `:57-58`）。
  - 通道：**55 个密采样** `dist_channels_km = [0.5,1,1.5,…,8,8.3,8.6,9,9.2,…,15,15.2]`（`:67-70`）。索引由 `int(d*1e3/dx)` 换算（`:75`），`dx = 16.0×1.020951986312866 ≈ 16.335 m`（`:74`）。
  - `fs = 80 Hz`（`:76`）。
- **输出**（基目录 `output_dir_base = _PKG_ROOT/noise_psd`，`:53`）：
  - `noise_psd/chunk0:40:00_nperseg200s/psd_daily_h5/YYYY-MM-DD.h5`（每天一个，`:143`）。内部结构（由建表代码确认）：
    - `frequency`：rfft 频率向量，长度 8001（nperseg = 200s×80Hz = 16000 样点 → rfft → 8001 bins，覆盖 0–40 Hz，Δf = 0.005 Hz），每天存一次（`:151-153`）。
    - 组 `ch_X.Xkm`（每通道一组，`:154-155`），组内数据集名 = 块起始时间戳 `YYYYmmddTHHMMSS`（`:144,182`），值 = 该块该通道 PSD `Pxx`，gzip 压缩（`:182`）。
  - `noise_psd/chunk0:40:00_nperseg200s/config.json`：本次全部参数（`:105-113`）。
- **核心数学操作（Welch 法 PSD，分步）**：
  1. 时间窗按 `chunk_duration = 40min` 切块（`:80,127-131`）。
  2. 每块读 DAS → 选 55 通道列 → `float64`（`:163-167`）。
  3. `nperseg = nperseg_seconds × fs = 200×80 = 16000` 样点（`:133,170`）；`freq = rfftfreq(nperseg, 1/fs)`（`:134`），Δf = 1/200s = 0.005 Hz。
  4. 逐通道 `scipy.signal.welch(trace, fs, nperseg, scaling='density')`（`:179`）：把该块 40min 单道序列切成多个长 16000 样点（200s）的重叠子段（默认 Hann 窗、50% 重叠），逐段加窗 FFT 取 `|·|²`，对子段平均，得单边功率谱密度 `Pxx`，单位 `(strain/s)²/Hz`。
  5. 存入 daily h5 对应通道组（`:181-182`）。
- **对数据的实际操作**：连续读 → 选通道 → Welch 平均降维 → 每块每通道存一条 PSD 谱。原始 DAS 不改。
- **断点续算 / 内存**：先查第一个通道组里是否已有该时间戳，有则跳过（`:158-160`）；每块 `finally` 删大对象并 `gc.collect()`（`:189-194`）。
- **依赖**：`functions/load_das_h5_PE2024.load_das_custom`（`:33-34,163`，经 `sys.path` 引入）；`scipy.signal.welch`、`numpy`、`h5py`、`json`、`tqdm`。

### 2.2 `2_plot_results_with_wind_wave.py` —— 谱图 + 振幅时序 + 叠加风/浪气象（科学集成图）

- **作用**：对每个通道画 3 联子图：① 时间-频率谱图；② 分频段 ASD 时序 + 右轴有效波高 SWH；③ 风速 + 右轴平均波周期 MWP。把 DAS 噪声与海况/风对比。纯出图，不产 h5。
- **输入**：
  - PSD daily h5（第 1 步产物）：`psd_data_dir = output_dir_base/chunk0:40:00_nperseg200s/psd_daily_h5`（`:434`，`nperseg=200/chunk=40min` 必须与第 1 步一致，`:427-428`）。
  - 时间窗当前激活全期 `2024-04-24 10:20 → 2024-06-22 17:10`（`:449-452`）。
  - 通道：**55 个密采样**（`:439-442`，与第 1 步一致）。
  - **气象（包内版改指本包 `meteo/`）**：`sys.path.append(_PKG_ROOT/"meteo")`（`:36`），`from load_kefa_meteo import load_kefa_meteo_data`（`:37`），运行调用 `atmos_df, wave_df = load_kefa_meteo_data(t_start, t_end)`（`:358`），用 `wave_df['swh']`、`wave_df['mwp']`、`atmos_df['wind_speed']`（`:364,376,385`）。气象 CSV 已随包放在 `meteo/`。
- **输出**：`noise_psd/chunk.../plots/<zoom串>/sg_meteo_channel_<km>.png`（每通道一张，`:403-404`）+ `plot_config.json`（`:496-497`）。
- **核心数学操作**：PSD→ASD `asd = sqrt(Pxx)`（`:306,337`），分频段在频率维取均值得曲线（`frequency_bins = [(0.02,1),(4,35)]`，`:462,338-348`）；谱图颜色 LogNorm（5/95 分位，`:309-310`）；气象部分无新数学，只叠时序曲线。
- **对数据的实际操作**：读 PSD daily h5 + 2 个气象 CSV，纯出图。
- **依赖**：本文件 `load_psd_data_from_daily_h5`（`:43`，返回 `(times, f, Pxx.T)` 形状 `(n_freq, n_time)`）、`plot_spectrogram_and_binned_timeseries`（`:263`，`__main__` 调用 `:531`）；本包 `meteo/load_kefa_meteo`；`functions/plot.Ticks_xaxis_day_or_hour / Ticks_xaxis_minute_or_second`（`:33`）。

### 2.3 `3_plot_ppsd.py` —— 概率功率谱密度（PPSD，McNamara-Buland 风格）

- **作用**：对每通道把长时间窗内**所有** PSD 谱在「频率×功率(dB)」平面做 2D 直方图、按频率归一为概率密度（PPSD）；另出「各通道某分位 PSD」的汇总热力图。纯出图，不产 h5。
- **输入**：PSD daily h5（`:46`，`nperseg=200/chunk=40min`，`:41-42`）；通道 55 个（`:50-53`）；时间窗全期 `2024-04-24 10:20 → 2024-06-22 17:10`（`:56-59`）。**本脚本不 import `functions`**，仅用 `_PKG_ROOT` 拼输出目录（`:30,38`）。
- **输出**：`noise_psd/chunk.../ppsd_plots/<时间串>/ppsd_chXpXkm_*.png`（每通道，`:242-243`）、`ppsd_summary_<P>percentile_*.png`（汇总，默认 P50，`:336,397`）、`ppsd_config.json`（`:86-87`）。
- **核心数学操作（PPSD，分步，`plot_single_channel_ppsd` `:150`）**：
  1. `psd_db = 10·log10(Pxx + 1e-25)`（`:170`，dB rel. 1 `(strain/s)²/Hz`）。
  2. 功率 bins `linspace(-220,-80,141)`（`:173`）；频率**对数** bins `logspace(log10(min_f),log10(max_f),100)`（`:182`）。
  3. 逐频率 bin 收集落入的 dB 值 → `np.histogram` 填 `hist2d`（`:185-201`）。
  4. 每频率 bin 计数 / 该 bin 总计数 ×100% → 概率密度 `ppsd`（`:204-208`）。
  5. `pcolormesh` 画（`:214-216`）。
  - 汇总图 `plot_summary_ppsd_percentile`（`:251`）：每通道 `psd_db` 沿时间维取分位（默认 P50，`:279,397`），堆 `[通道×频率]` 矩阵画热力图（`:282,301`）。
- **对数据的实际操作**：把整段时间所有 PSD 压成统计分布，直接出图。
- **依赖**：本文件 `load_psd_data_from_daily_h5`（`:95`，返回 `(times, f, Pxx)` 形状 `(n_time, n_freq)`）；`numpy`、`matplotlib`、`h5py`、`tqdm`。

### 2.4 `4_analyse_noise_trends.py` —— 噪声趋势分析（★产出包内成品 noise_trends h5）

- **作用**：把 PSD 在频带 `(8,20)Hz` 上取 **P5 分位**、开方得「噪声振幅代理量」，对**所有 55 通道 × 所有时间步**组装矩阵，存 `noise_trends_f8-20Hz_p5.h5`，并出**双面板图**（热力图 + 下方区段平均噪声曲线）+ 每通道子图。**此 h5 即被 MF 发布版引用的成品。**
- **输入**：PSD daily h5（`:53`，`nperseg=200/chunk=40min`，`:48-49`）；分析时间窗全期 `2024-04-24 10:20 → 2024-06-22 17:10`（`:61-62`）；时间步 `time_step_duration = chunk_duration = 40min`（`:69`）；频带 `frequency_band = (8,20)`（`:76`，低频版 `(0.02,1)` 已注释 `:77`）；分位 `percentile_to_calculate = 5`（`:80`）；分析通道 55 个（`:84-87`）；**区段平均通道** `channels_to_average_noise_level = [8.3,…,14]`（28 个，`:89-91`，对应「9–14 km 段」平均，用于下面板曲线）。
- **输出**（目录 `noise_psd/chunk0:40:00_nperseg200s/noise_trend_plot/20240424_102000-20240622_171000_step0:40:00/`，`:96`）：
  - **`noise_trends_f8-20Hz_p5.h5`**（`:100`；命名规则 `noise_trends_f{f0}-{f1}Hz_p{P}.h5`，`:99-100`）。**结构（与包内 `products/` 同名成品实测一致）**：
    - 数据集 `noise_amplitude`：`float64`，形状 **`(2135, 55)`** = `[时间步, 通道]`，`chunks=(10,55)`、gzip（`:208-209`）。
    - 数据集 `timestamps_utc_str`：`|S19` 字节串，格式 `%Y-%m-%dT%H:%M:%S`（每时间步起点；实测首 `2024-04-24T10:20:00`、末 `2024-06-22T17:00:00`，`:213-214`）。
    - 数据集 `channels_km`：`float64`，形状 `(55,)`，0.5…15.2 km（`:215`）。
    - 属性（实测）：`amplitude_unit="(strain/s)/sqrt(Hz)"`、`amplitude_description="sqrt(P5 of PSD)"`、`frequency_band_hz="(8, 20)"`、`time_step_duration="0:40:00"`、`description`、`creation_date_utc`（`:218-223`）。
  - 双面板热力图 PNG `noise_heatmap_f8-20Hz_p5.png`（`:101`）、每通道子图 PNG `noise_subplots_*`（`:102`）、`noise_analysis_config.json`（`:124`）。
- **核心数学操作（噪声代理量，分步，`calculate_noise_level` `:172`）**：
  1. 取频带 `8 ≤ f ≤ 20 Hz` 频点索引（`:183`）。
  2. 取这些频点上该时间步所有 PSD 段的功率 `psd_in_band`（`:188`）。
  3. **跨「时间段×频点」整体展平取 P5 分位** `power_at_percentile = np.percentile(psd_in_band, 5)`（`:192`）——P5 取低端「安静本底」水平作代理。
  4. **开方** `noise_amplitude = sqrt(power_at_percentile)`（`:196`），单位 `(strain/s)/sqrt(Hz)`。
  - 主循环：外层通道、内层时间步，逐格 `load_psd_data_from_daily_h5` + `calculate_noise_level` → `results_matrix[i,j]`（`:485-505`）。
  - 双面板下面板：取 `channels_to_average_noise_level` 对应列，沿通道维 `np.nanmean` 得「9–14 km 段平均噪声」时序曲线（`:320-335`），对数 y 轴画。
- **对数据的实际操作**：把 PSD 谱按 (8-20Hz, P5) 打分成标量 → 组装时间×通道矩阵 → 存盘 + 画图。
- **依赖**：本文件 `load_psd_data_from_daily_h5`（`:133`）、`calculate_noise_level`（`:172`）、`save_results_to_h5`（`:200`）、`plot_noise_heatmap`（`:230`，双面板版）、`plot_noise_subplots`（`:371`）；`functions/plot.Ticks_xaxis_*`（`:33`）；`numpy`、`h5py`、`matplotlib`、`tqdm`。

## 五、数据 / 产物说明

### 5.1 PSD daily h5（第 1 步产物，**中间产物，不随包带**）

- 路径：`noise_psd/chunk0:40:00_nperseg200s/psd_daily_h5/YYYY-MM-DD.h5`（每天一个）。
- 结构：`frequency`（长 8001，0–40 Hz，Δf=0.005 Hz）+ 每通道组 `ch_X.Xkm`，组内数据集名 = 块起始时间戳 `YYYYmmddTHHMMSS`，值 = PSD `Pxx`（单位 `(strain/s)²/Hz`，gzip）。

### 5.2 noise_trends h5（第 4 步产物，★主线成品 / MF 依赖契约）
