# 中间数据范例：单日 PSD h5

> **GitHub 版说明：** 这里说的 h5 文件**不在本仓库里**（只有本说明）。69.3 MB 的单日 PSD 文件 `2024-04-24.h5`（72,712,352 字节）在 Zenodo 存档 [10.5281/zenodo.20715241](https://doi.org/10.5281/zenodo.20715241) 里（`matched_filter_release.zip` → `check_minmag_pkg/noise_psd/example_outputs/sample_intermediate_psd_daily/2024-04-24.h5`）。可拷到本目录，或拷到 `noise_psd/chunk0:40:00_nperseg200s/psd_daily_h5/` 作为脚本 2_/3_/4_ 的输入。

`2024-04-24.h5`（~70MB）是 `noise_psd/1_calculate_psd_h5.py` 的**中间产物范例**——单日逐通道的 Welch PSD。

- **由谁产生**：`1_calculate_psd_h5.py`（DAS → 按天一个 h5）。
- **结构**：`frequency`（长 8001，0–40Hz，Δf=0.005Hz）+ 每通道一组 `ch_X.Xkm/`，组内数据集名=该 40min 块起始时间戳 `YYYYmmddTHHMMSS`，值=该块该通道 PSD `Pxx`（单位 `(strain/s)²/Hz`）。
- **被谁消费**：`2_plot_results_with_wind_wave.py` / `3_plot_ppsd.py` / `4_analyse_noise_trends.py`。

> 这里只放**一天**作范例参考。全量（2024-04-24 → 06-22 共 60 天、约 6.9GB）不随包附带，可由 `1_calculate_psd_h5.py` 在外部连续 DAS 上重算。
