# functions/ 说明文档

## 一、内容与作用

本文件夹只收录两个公共模块，是本包所选脚本【真正 import 用到】的全部 `functions` 依赖：

| 模块 | 作用 | 被谁调用 |
|---|---|---|
| `load_das_h5_PE2024.py` | DAS HDF5 自定义加载器（核心函数 `load_das_custom`），按时间窗读取连续 DAS 数据 | `noise_psd/1_calculate_psd_h5.py`、`eq_spectra/1_calculate_psd_by_eq.py`、`eq_spectra/1_calculate_psd_by_eq_Parallel.py`、`noise_psd/2_`、`noise_psd/4_`（后两者 import 但读 DAS 实际在 1_ 完成） |
| `plot.py` | 绘图辅助（`Ticks_xaxis_day_or_hour` / `Ticks_xaxis_minute_or_second` 等时间轴刻度格式化函数） | `noise_psd/2_plot_results_with_wind_wave.py`、`noise_psd/4_analyse_noise_trends.py` |

**为何只收这两个**：用 grep 核对本包所选 7 个脚本真正 `import` 的 `functions` 符号，只用到 `load_das_h5_PE2024` 与 `plot`，因此只收这两个模块。原 `check_minmag` 工程 `functions/` 下的其它模块（`compute_correlation`、`trigger`、`classify`、`extract`、`extract_station_info`、`cluster`、`readers`、`das_mffi_io`、`append_cut_convert`、`stalta` 等，以及整个 `pydas_readers/` 目录）本包脚本均未 import，已剔除。

实测说明：`load_das_h5_PE2024.py` 是自包含的——全文只 import 标准库（`os`/`sys`/`glob`/`datetime` 等）+ `h5py` + `numpy`，**不依赖** `pydas_readers/` 或任何其它 `functions` 模块。已实测 `import load_das_h5_PE2024` 仅靠自身即可成功导入并取到 `load_das_custom`，无 `pydas_readers` 依赖（即规划文档中"依赖 pydas_readers"的推测不成立）。`plot.py` 只 import `matplotlib` + `numpy`。两者均无需附带传递依赖。

## 二、逐脚本说明（输入输出/数据流）

### `load_das_h5_PE2024.py`

- 出处：源自 Pascal Edme (ETH Zürich) 读取 Silixa iDASv2 / 降采样后 DAS HDF5 文件的工具，2023 年版本。
- 主要函数：
  - `load_headers_only(file)`：只读单个 h5 的头信息（不读大数据块），返回 dict，含 `fs`（采样率，由 `1000/step` 得到）、`dx`（通道间距）、`nchan`、`npts`、`t0`/`t1`（由文件名按 `%Y%m%d_%H%M%S.%f.h5` 推得）、`d0`/`d1`（沿光纤起止距离）、`amp_scaling`（幅值标定，默认 1）等。
  - `load_file(file)`：读单个 h5 的 `Traces` 数据集，除以 `amp_scaling` 转为应变率单位 `(m/m)/s`，返回 `(data, headers, axis)`，`data` 形状 `[样本数, 通道数]`。
  - **`load_das_custom(t_start, t_end, d_start=0, d_end=0, input_dir, nth_channel=1, ...)`** —— 本包脚本实际调用的入口：
    - 输入：起止 `datetime`、可选沿光纤距离范围 `d_start`/`d_end`、数据目录 `input_dir`、可选抽道步长 `nth_channel`。
    - 行为：在 `input_dir` 内按文件名时间戳定位、跨文件/跨天拼接，只取所需时间（和距离）区间，避免整块读入。
    - 输出：`(data, headers, axis)`，`data` 为 `[样本数, 通道数]` 的应变率数组，`axis` 含 `tt`（秒）/`date_times`（绝对时间）/`dd`（通道距离）。
- 调用点：
  - `noise_psd/1_calculate_psd_h5.py:163` —— `load_das_custom(t_start, t_end, input_dir=DAS_DATA_DIR)` 读连续 DAS 算 Welch PSD。
  - `eq_spectra/1_calculate_psd_by_eq.py:129`（及 `_Parallel.py`）—— 同样用 `load_das_custom` 读触发时刻附近的 DAS 算逐事件 PSD。

### `plot.py`

- 内容：matplotlib 绘图辅助函数。本包实际用到的是两个时间轴刻度格式化器：
  - `Ticks_xaxis_day_or_hour(ax, Day_tick, Hour_tick, rotation, font)`：按"天"或"小时"间隔设置主/次刻度与日期格式。
  - `Ticks_xaxis_minute_or_second(ax, Minute_tick, Second_tick, rotation, font)`：按"分"或"秒"间隔设置刻度。
  - 另含 `waterfall_date`、`generate_gs_grid` 等辅助函数（本包当前脚本未直接调用，但随模块附带）。
- 调用点：`noise_psd/2_` 与 `noise_psd/4_` 在出图时 `from plot import Ticks_xaxis_day_or_hour, Ticks_xaxis_minute_or_second`。

## 三、与本包其它部分及 MF 的衔接

- 本文件夹是**计算/绘图侧的底层依赖**，被 `noise_psd/` 与 `eq_spectra/` 的脚本通过 `sys.path` 加入后 import（各脚本顶部以 `_PKG_ROOT/functions` 推导路径，相对 `__file__`，不写绝对路径）。
- 本文件夹**不**直接对配套 MF 发布版（`WANGYuhan2002/yuhan-mfdas`，Zenodo `matched_filter_release.zip` 中为 `yuhan_dasmf_v1.0/`）输出任何接口或成品——MF 侧消费的是 `meteo/`（气象加载模块 + CSV）与 `products/`（噪声成品 h5），而非 `functions/`。`functions/` 只在"从头重算 PSD / 地震谱"时才被本包脚本使用；MF 直接用已冻结的成品，不触及本文件夹。
